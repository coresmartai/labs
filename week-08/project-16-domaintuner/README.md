# Project 16: DomainTuner

This folder is your starting point for the Week 8 graded project. Replace this file with your own
README, using the template on the LMS.

**The brief, the rubric and the submission checklist are in Section 4 of Week 8.** Read
`Requirements and Rubric` before you write any examples: the choice of task is worth four marks and
it is the one decision that cannot be fixed later.

## What goes where

| Path | What you put in it |
|---|---|
| `data/train.jsonl` | Your training examples, about fifty, one JSON object per line |
| `data/eval.jsonl` | Your evaluation questions, at least twenty, with accepted answers |
| `results/base.json` | The untrained row, emitted by the harness |
| `results/tuned.json` | The tuned row, from the same evaluation |
| `MEMO.md` | The table and the paragraph. This is the deliverable |
| `config-notes.md` | Which rank, which target modules, and why |
| `README.md` | This file, replaced with yours |

## The one thing to do first

Write ten training examples by hand before you write any code. If ten is hard, that is real
information about your task, and Monday is a far better day to find that out than Friday.
