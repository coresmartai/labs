# Your data goes here

Two files, both committed, and no question may appear in both.

## `train.jsonl`

One JSON object per line. The same shape the guided build used, so the pipeline reads it unchanged:

```
{"messages": [{"role": "user", "content": "..."}, {"role": "assistant", "content": "..."}]}
```

The assistant turn is the answer you are teaching, in the register and at the length you want.
Length is taught as much as content, so an answer three times longer than you want teaches that too.

**About fifty of these.** Fewer is banded rather than forbidden, and the brief says exactly how.

**Write them yourself.** Examples generated by the model you are about to train score zero on that
rubric line, because the model already produces them and there is nothing in them to learn.

## `eval.jsonl`

One JSON object per line, with an accepted-answer list so the harness can score without a second
model:

```
{"id": "q01", "question": "...", "expected": "...", "accept": ["...", "..."], "category": "..."}
```

**At least twenty.** The `accept` list is what the substring scoring checks for, so put every
reasonable phrasing of the key idea in it. A thin accept list marks correct answers wrong and makes
your own result look worse than it is.

`category` is optional and worth adding. The per-category breakdown is far more informative than the
overall number, and noticing that one category got worse is exactly the kind of finding the memo
rewards.
