## If you have arrived here before doing prep week in the LMS

You need two things before Week 1, and only one of them is in this repository.

**The environment check** is the notebook above. Run it first.

**Your own course repository** is not here and cannot be. You create it once,
by pressing **Use this template** on
[coresmartai/genai-17-template](https://github.com/coresmartai/genai-17-template)
and naming it `genai-17`. It lands in your own GitHub account. There is no
invitation to accept and nothing to request.

Every step, in order, with the screenshots, is in the prep week module in the
LMS. This page exists so that a learner who reaches GitHub before reaching that
page is not stuck, not to replace it.

## What this folder is not

You do not build here. This repository is read-only reference for every cohort.
Your work lives in your `genai-17` repository, and each week's brief tells you
exactly what to copy across.
